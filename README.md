## 🛠️ Featured Projects & Lab Repositories

* **[Infrastructure & Automation Labs](https://github.com/isaac-padilla/infrastructure-and-automation-labs)**
  Laboratorio principal con despliegues de Terraform para GCP, scripts de automatización de mantenimiento en Linux y configuraciones de contenedores.

* **[Self-Hosted Media & Automation Ecosystem](https://github.com/isaac-padilla)**
  Ecosistema orquestado con Docker Compose (Jellyfin, Sonarr, Radarr, Prowlarr) con tunelización segura vía Tailscale VPN Mesh sin apertura de puertos. Incluye políticas de auto-recuperación ante fallos de energía.

* **[Linux Server Health Monitor (Raw Bash)](https://github.com/isaac-padilla)**
  Monitor en tiempo real en Bash que parsea métricas directamente desde `/proc`, `free`, `df` y `ps` para auditar consumo de CPU, RAM y procesos sin dependencias de terceros.
